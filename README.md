**FractalSNN** — сверхлегковесная, энергоэффективная спайковая нейронная сеть (SNN) третьего поколения, написанная с нуля на чистом **Free Pascal**. 

В основе лежит авторская древовидно-фрактальная дендритная модель нейрона (**f-LIF**) с логарифмически распределенным спектром констант утечки ($\beta \in [0.85, 0.995]$), позволяющая захватывать как высокочастотные импульсы, так и долговременный временной контекст.

Разработано для применения в промышленной автоматизации (ЧПУ, вибродиагностика подшипников), анализе телеметрии в реальном времени и Edge-системах без использования GPU и тяжелых Python-стеков.

---

## 🔬 Доказанные характеристики ядра

* **Высокая избирательность**: **91.3%** точности на связанных временных задачах с задержкой (против **63.2%** у классического монолитного LIF, $p < 0.0001$).
* **Биологическая разреженность**: средняя активность нейронов **5–15%** (в 85–95% тактов вычисления не требуют мощности).
* **Стойкость к квантованию (INT4)**: падение точности менее **2.3%** при сжатии весов в 4 бита.
* **Самоорганизованная критичность**: подтвержденный показатель $D_{box} > 1.25$ на двумерном спайковом растре активности.
* **Компактность**: файл обученных весов и структуры занимает **$\le 30$ КБ**.

## Требования
Компилятор Free Pascal Compiler (fpc) версии 3.2.0 или новее.

## Сборка и запуск тестов

git clone https://github.com/trembachvv/FractalSNN.git
cd FractalSNN/tests
chmod +x run_all_tests.sh
./run_all_tests.sh

Каждый тест компилируется начисто и выдает вердикт:
CI VERDICT: ALL TESTS PASSED SUCCESSFULLY (100% PASS).

## Как запустить бенчмарк

Bash
cd ~/LasarusProjects/FractalSNN/benchmarks
fpc -O3 -Mobjfpc -S2 -Si -Fu../src run_benchmarks.pas
./run_benchmarks

После завершения все файлы отчётов окажутся внутри benchmarks/results/.
